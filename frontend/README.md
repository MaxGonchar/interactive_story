# Interactive Story — Frontend

React + Vite frontend for the Interactive Story app.

## Requirements

- Node.js >= 20.19.0
- npm >= 10.8

## Setup

```bash
cd frontend
npm install
```

## Development

```bash
npm run dev
# open http://localhost:5173
```

## Notes

- Routing, API client, and component library are intentionally deferred to later milestones.
- This scaffold renders a single placeholder heading (M1 skeleton).
